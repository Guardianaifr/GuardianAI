# Customer-Facing Assurance Layer

This folder contains the customer-facing assurance package for sales, procurement, and compliance due diligence.

## Contents

- `CUSTOMER_PROFILE_REQUIREMENTS_MATRIX.md`
  - Buyer-segment requirements and mapped evidence.
- `FRAMEWORK_CONTROL_MAPPING.md`
  - SOC2/HIPAA/GDPR/AI Act-oriented control mapping.
- `ENTERPRISE_PROCUREMENT_PACKET.md`
  - Structured packet checklist for enterprise procurement review.
- `NAMED_ASSURANCE_STATEMENT.md`
  - Named, dated assurance statement with evidence links.
- `SECURITY_QUESTIONNAIRE_QUICK_ANSWERS.md`
  - Fast-response template for common security questionnaires.
