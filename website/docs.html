    GuardianAI Technical Documentation

    Dual-plane security for autonomous AI agents: sub-millisecond prompt injection firewalls off-chain, coupled with cryptographically verifiable ERC-8004 identity and evidence anchoring on-chain.

    🛡

    Off-Chain Layer

    10-layer heuristic, regex, semantic, and de-obfuscation firewall filtering attacks in under 42ms p95.
    ⛑

    On-Chain Layer

    ERC-8004 agent registries, Merkle tree state anchors, and signed insurance certificate registries.
    ⚡

    5-Min Setup

    Drop-in proxy or single-line Python SDK wrapper for OpenAI, Anthropic, LangChain, and CrewAI.
    🔍

    Contract Analyzer

    48 AST/CFG validated vulnerability detection rules for Solidity & Vyper smart contracts.
    💡 Core Design Philosophy
    Every AI agent makes promises to its users. GuardianAI provides the cryptographic infrastructure and runtime firewalls to continuously verify those promises without requiring trust in proprietary black boxes.

    Quickstart (5-Minute Integration)

    Integrate GuardianAI into your existing autonomous agent stack in minutes using either our reverse proxy or the native Python SDK.

    Option A: OpenAI-Compatible Ingress Proxy

    Point your existing client code to the Guardian proxy host (http://127.0.0.1:8081 or your managed cloud gateway) by simply updating the base_url:

    from openai import OpenAI

# Route completions directly through the GuardianAI Security Proxy
client = OpenAI(
    base_url="http://127.0.0.1:8081/v1",
    api_key="your-guardian-api-token"
)

response = client.chat.completions.create(
    model="gpt-5.6",
    messages=[{"role": "user", "content": "Deploy trading agent transaction"}]
)
print(response.choices[0].message.content)
    curl -X POST http://127.0.0.1:8081/v1/chat/completions \

  -d '{
    "model": "gpt-5.6",

  }'

    3-Layer Defense-in-Depth Architecture

    GuardianAI separates agent security into three coordinated defense layers to deliver sub-millisecond threat filtering, hardware-bound sovereign memory isolation, and deterministic on-chain execution containment.

    Defense Layer Target Execution Core Responsibilities Performance & SLA
    Layer 1: Edge AI Firewall Off-Chain Ingress Proxy & Gateway 10-layer prompt firewall, de-obfuscation pipeline, PII/secret DLP scrubber, honeypot canary tripwires, fail-closed token bucket < 42 ms p95 under attack, 494 req/s blocking capacity
    Layer 2: Sovereign Agent Enclave WebAuthn PRF & Hardware Memory Sealing Category Labs Mera Passkey PRF key derivation, AES-256-GCM sealed memory with replay-protected AAD, active MEMORY_POISONING_DETECTED tamper tripwire Sub-0.5ms P50 latency, 184/184 tests, 0 collisions across 4 GitHub corpora
    Layer 3: Execution Containment Monad Parallel EVM Smart Contracts GuardianPolicyGuard.sol pre-flight execution firewall, GuardianThreatConsumer.sol Chainlink oracle sync, ERC-8004 identity, Merkle Cortex state anchoring 207/207 Hardhat tests (11 suites), zero-contention parallel execution up to 10k TPS

    10-Layer AI Prompt Firewall

    Every incoming prompt passes through a progressive 10-stage defense-in-depth pipeline. Fast heuristics reject obvious attacks in microseconds, while deeper semantic and de-obfuscation engines neutralize advanced multi-turn and obfuscated jailbreaks.

    1. Regex Fast-Path

    Known jailbreak prefixes, instruction reset patterns, and exploit signatures evaluated in < 0.5ms.

    2. Shannon Entropy Filter

    Detects high-entropy encrypted blobs, raw binary payloads, and compressed ciphertext attacks.

    3. Steganography & Cipher Engine

    Automated decoding for Braille, Morse code, Base64, Hex, ROT13, Leetspeak, and Unicode homoglyphs.

    4. Semantic Classifier

    Fine-tuned lightweight classifier scoring adversarial intent, DAN variants, and system-prompt extraction.

    5. Multi-Lingual Translation Gate

    Normalizes cross-lingual evasion attempts in Chinese, Russian, Arabic, and low-resource languages.

    6. Token Smuggling / Zero-Width

    Strips zero-width joiners, invisible unicode separators, and RTL directional override exploits.

    7. Roleplay & Virtualization Filter

    Neutralizes "fictional scenarios", "debug mode", "developer override", and hypothetical simulation prompts.

    8. Tool Calling & Transaction Interlock

    Validates tool arguments against strict schema constraints; blocks unauthorized wallet transfers and parameter tampering.

    9. Honeypot Canary Engine

    Plants synthetic credentials in system context; triggers immediate session quarantine if referenced.

    10. Threat Intelligence Matcher

    Live matching against globally synchronized IOC feeds and newly cataloged zero-day prompt signatures.

    Fail-Closed Rate Limiter

    To defend against denial-of-wallet and automated prompt bombing, GuardianAI implements a strict fail-closed token-bucket rate limiter powered by atomic Redis Lua scripts (_REDIS_RATE_LIMIT_LUA) for zero-drift distributed replenishment. In-memory local buckets are bounded to 50,000 entries and continually swept by a 60-second RateLimiterJanitor daemon. If backing services experience downtime, GuardianAI safely restricts requests rather than failing open.

    Tier Rate Limit (Req/Min) Burst Allowance Rate Limit Backend
    Standard Ingress 100 req/min 20 requests In-Memory Ring Buffer
    High-Throughput Gateway 1,000 req/min 150 requests Redis Distributed Cluster
    Dedicated Cluster Unlimited / Custom Custom SLA Dedicated Redis Multi-Region

    Mera Passkey PRF Sovereign Enclave (Layer 2)

    Built in collaboration with Category Labs, GuardianAI’s Sovereign Agent Enclave harnesses client-side WebAuthn Pseudo-Random Functions (PRF) (FaceID, TouchID, and FIDO2 hardware authenticators) to generate deterministic, unlinkable agent identities without storing raw private keys or master secrets on any server.

    Hardware-Bound PRF Keys

    Master seed derived within local device Secure Enclave; never leaves client RAM and cannot be exfiltrated via server-side compromise.

    AES-256-GCM Memory Sealing

    Agent episodic memory vectors and tool credentials encrypted with HKDF-derived keys and replay-protected Additional Authenticated Data (AAD).

    Cross-Device Determinism

    Same physical human authenticator generates identical agent DIDs and decrypts sealed state across independent devices.

    Live Benchmark Receipts

    184/184 tests passing (18 core Vitest + 166 hard audit assertions on 4 live GitHub corpora), sub-0.5ms P50 latency, 0 collisions.

    Memory Poisoning Guard & Tamper Tripwire

    Autonomous agents that consume external web data, pull requests, or Discord messages risk context injection and persistent memory poisoning. GuardianAI embeds an active cryptographic tamper tripwire directly into the memory retrieval path.

    Tamper Detection & Quarantine Flow 
    // Memory retrieval verification in @guardianai/middleware
try {
  const decryptedContext = await enclave.unsealMemory(agentId, sealedRecord);
  return decryptedContext;
} catch (err) {
  if (err.code === "ERR_GCM_AUTH_FAILED" || err.message.includes("tag mismatch")) {
    // Single-bit ciphertext flip trips immediate fail-closed quarantine
    await securityPipeline.quarantineAgent(agentId, {
      code: "MEMORY_POISONING_DETECTED",
      incidentSeverity: "CRITICAL",
      action: "REVOKE_HOT_WALLET_PERMISSIONS"
    });
    throw new SecurityException("Agent context compromised: Memory poisoning tripwire fired.");
  }
}

    Monad PolicyGuard (Layer 3 Execution Containment)

    GuardianAI deploys native smart contracts to the Monad Parallel EVM (Chain ID 10143). The flagship execution firewall, GuardianPolicyGuard.sol, enforces 10 deterministic on-chain invariants before autonomous agent transactions are broadcast.

    🔗 Full-Match Verified on MonadVision
    GuardianPolicyGuard is deployed and verified at 0x32fa...1101 ↗. Verified test suite: 207 Hardhat unit, stress, and reorg tests (100% passing across 11 suites).

    Storage Slot Isolation

    Nonces keyed by keccak256(agentId, nonce) ensure independent agents execute concurrently on Monad with zero storage slot contention (up to 10k TPS).

    128 KB Bytecode Capacity

    Leverages Monad's 128 KB bytecode limit to bundle complete policy matrices, parameter checks, and signature verifications without proxy fragmentation.

    24h Outflow Volume Caps

    Enforces strict per-agent rolling expenditure thresholds; blocks automated wallet drains if an agent is tricked into over-spending.

    Sub-Second EIP-712 Attestation

    Identity Registry

    Identity Gate & Enforcement

    Reputation Registry

    Validation Registry

    Merkle Cortex State Anchoring

    GuardianAI aggregates telemetry events into episodic memory batches, constructs a cryptographic Merkle tree, and periodically anchors the 32-byte root hash to the blockchain. Trees strictly follow RFC 6962 domain separation (using a 0x01 internal node prefix) and promote odd trailing leaves directly to parent tiers, completely preventing Bitcoin-style (CVE-2012-2459) duplicate-leaf collision and second-preimage attacks.

    API Reference: Ingress Proxy

    POST /v1/chat/completions

    Sends a standard chat completion request through Guardian's 10-layer firewall.

    Header / Param Type Description
    Authorization Header (Bearer) Your GuardianAI project API key or tenant JWT.
    model String (Body) Target model (e.g. gpt-5.6, claude-opus-5, glm-5.3, deepseek-r1, o3-mini).
    messages Array (Body) Array of message objects with role and content.

    Response Status Codes:

    • 200 OK: Prompt passed all security layers; upstream model response returned.
    • 403 Forbidden: Attack detected and blocked. Response contains detailed rule match metadata.
    • 413 Payload Too Large: Request entity exceeded the 10MB gateway body ceiling (MAX_CONTENT_LENGTH).
    • 429 Too Many Requests: Rate limit exceeded (fail-closed protection triggered).
